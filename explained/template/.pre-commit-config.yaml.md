# template/.pre-commit-config.yaml

**What it is:** the checks a project runs on every `git commit`. If one fails, the commit is blocked. Turn them on once per clone with `uv run pre-commit install` (part of the README's first-time setup).

**What runs:**

| Hook | What it does |
| --- | --- |
| `gitleaks` | Blocks commits that contain passwords, keys or tokens. Pinned to the exact commit of v8.30.1 (`# frozen:`), because tags can be moved |
| `ruff check` | Lint, with the project's own Ruff (the version in `uv.lock`, run through `uv run`) |
| `ruff format --check` | Formatting, checked but not changed |

Both Ruff hooks pass `--force-exclude`. Without it, Ruff checks every file pre-commit names, even ones its settings exclude, such as migrations.

**One limit:** gitleaks only checks what's staged, so `pre-commit run --all-files` isn't a full secret scan. The README gives Docker commands that scan every file and the whole history.

The gitleaks version must match the starter's own hook and the Docker commands in both READMEs.

**`django-missing-migrations`:** a local hook that runs `scripts/check-migrations.sh` (`makemigrations --check --dry-run`) and blocks a commit that changes models without a migration — the mistake parallel agents most often make.
