# template/.worktreeinclude → .worktreeinclude

**What it is:** the list of git-ignored files Claude Code copies into each new worktree (`claude -w <name>`).

**What's in it:** `.env` — so every worktree has the project's environment (database settings, secrets, and the `PORT` that `scripts/wt-env.sh` then makes unique). Without this, a new worktree would start with no `.env` and nothing would run.
