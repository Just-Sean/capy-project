# template/templates/500.html

**What it is:** the "Something went wrong" page (status 500), shown when the site crashes. It says the problem has been logged and asks the visitor to try again later. The error itself goes to the logs with its stack trace (see `settings/logs.py`).

**Django renders it with no request and no data,** because what failed may be the database. Keep it that way: no tags that need the request, the user or a query, in this file or in `base.html`, which it extends. `tests/test_error_pages.py` checks that it still renders with the database and Redis both down.
