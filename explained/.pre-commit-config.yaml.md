# .pre-commit-config.yaml (the starter's own)

**What it is:** the check that runs on every commit to the starter repo. New projects get their own, from `template/.pre-commit-config.yaml`, which adds Ruff.

**What it runs:** **gitleaks**, which blocks a commit that contains a password, key or token. It's pinned to the exact commit of the v8.30.1 tag (`# frozen: v8.30.1`), because a tag can be moved.

**Setup, once per clone:** `uv tool install pre-commit`, then `pre-commit install`.

**Updating:** `pre-commit autoupdate --freeze`. The version must match the template's hook and the Docker commands in both READMEs, which makes four places in all (see "Updating gitleaks" in `README.md`).
