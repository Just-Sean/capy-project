# .gitignore (the starter's own)

**What it is:** the files the starter repo itself never commits. New projects get a different list, from `template/.gitignore.jinja`.

**What's in it:**

- **Secrets:** every file whose name starts with `.env`, in any folder, except files named `.env.example.jinja` (the template's example).
- **Tool output:** `.venv/`, `__pycache__/`, `*.pyc`, `.pytest_cache/`, `.ruff_cache/`, coverage files and `htmlcov/`.
- **Django output from trying the app in place:** `media/`, `media-public/` and `staticfiles/`.

**Why it matters beyond this repo:** `copier copy --vcs-ref=HEAD` from a local checkout includes uncommitted changes. So any file this list doesn't ignore could end up in a new project, a stray `.env` included.
